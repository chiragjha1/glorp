# Glorp — Accessibility Audit Assistant Frontend

> **"AI can build a website in seconds. But can it tell you if everyone can use it?"**

Glorp is a cinematic, developer-first accessibility auditing platform. Built with Next.js 15, TypeScript, Tailwind CSS, and custom WebGL shaders, it provides deterministic accessibility diagnostics powered by Axe Core and context-aware AI code remediation.

---

## ✦ Key Architectural Principles

1. **Deterministic Verification Architecture**:
   Glorp strictly decouples scanner detection from AI reasoning.
   - **`DETECTED`**: What the accessibility engine actually detected in the rendered DOM.
   - **`EVIDENCE`**: The raw HTML node, selector path, and engine rule failure summary.
   - **`PROPOSED FIX`**: Prescriptive guidance from the rule registry and suggested source diffs.
   - **`AI INSIGHT`**: Explanatory reasoning and context-aware assistance generated by the model.

2. **Conservative Verification Delta Semantics**:
   When re-evaluating after a code modification, Glorp categorizes findings into four truthful states:
   - `REMAINING`: Violations persisting in the fresh scan.
   - `NEWLY DETECTED`: Regressions or newly uncovered violations.
   - `NO LONGER DETECTED`: Absent from the current rendered DOM (conservatively labeled, never automatically claimed as "fixed" without proof).
   - `UNCERTAIN`: Ambiguous matches due to node restructuring or relocation.

3. **Liquid Glass & WebGL Computational Motion**:
   - Full-viewport WebGL fragment shader simulating dark computational silk and fluid folds.
   - Multi-layer liquid glass surface with subtle specular highlights, inner shadows, and backdrop saturation.
   - Editorial typography driven by Advercase / Instrument Serif italics paired with crisp technical monospace.

## ✦ Project Structure

```text

├── app/

│   ├── ShaderBackground.tsx # WebGL fragment shader with domain-warped FBM fluid

│   ├── AuditResults.tsx     # Editorial results view & filter coordinator
│   ├── FindingCard.tsx      # Violations card (Detection, Evidence, Fix, AI Insight)
│   ├── EvidenceBlock.tsx    # Raw DOM node, selector path, and failure summary
│   ├── ProposedFix.tsx      # Rule registry guidance, diff preview & AI context
│   ├── StatusBadge.tsx      # Impact, Gate, and Delta badges

    ├── types.ts            # Normalized MCP data contract (ScanRun, Finding, etc.)
    ├── api.ts              # API abstraction (auditPage, verifyFixes)
    └── mockData.ts         # Realistic Axe Core audit run covering 6 core categories
```

## ✦ Getting Started

### 1. Install Dependencies
```bash
pnpm install
```

### 2. Run Development Server
```bash
pnpm dev --port 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Connect to Backend MCP / API
To connect the frontend to a running Glorp MCP server or HTTP proxy:
```bash
# In .env.local
NEXT_PUBLIC_GLORP_API_URL=http://localhost:8000
```
If no backend URL is provided, Glorp automatically runs in local simulation mode with realistic audit and verification data.
